# Large analysis objects

Large serialized R objects generated during the analysis are intentionally
excluded from Git because individual files are approximately 3–6 GB.

The repository contains the complete analysis scripts and compact processed
results/source data. Selected large checkpoint objects will be archived
separately with the project data release so that users can restart major
downstream analysis stages without recomputing the entire single-cell
multi-omics workflow.

## Objects selected for external archival

| File | Approx. size | Role | Archive |
|---|---:|---|---|
| `decont_merged_filt_nodoub_cc_sct_reduc_clust_integ_annot_obj.rds` | 6.247 GiB | Final annotated human multiome Seurat object; input to cell-composition, hdWGCNA, and CellChat analyses | Yes |
| `hdWGCNA_obj.rds` | 2.905 GiB | hdWGCNA checkpoint; input to TF-network and Monocle3 analyses | Yes |
| `hdWGCNA_TFNet_obj.rds` | 2.961 GiB | Strategy-C TF regulatory-network checkpoint | Yes |
| `hdWGCNA_TFNet_B_obj.rds` | 2.955 GiB | Strategy-B TF regulatory-network checkpoint | Yes |
| `hdWGCNA_TFNet_DEReg_L2G_obj.rds` | 3.338 GiB | Differential-regulon/link-to-gene checkpoint; input to footprint and chromVAR analyses | Yes |
| `hdWGCNA_TFNet_DEReg_L2G_chromVAR_obj.rds` | 3.423 GiB | Human chromVAR analysis checkpoint | Yes |
| `hdWGCNA_TFNet_DEReg_L2G_Foot_obj.rds` | 3.390 GiB | Motif-footprinting analysis checkpoint | Yes |

Approximate total size: **25.219 GiB**.

These files are not committed to Git. Their public archive location and
persistent identifier will be added after creation of the project data
release.

## Intermediate checkpoints not selected for archival

The following objects are internal checkpoints produced and consumed within
`scripts/01A_Single_Cell_Analysis.R`. They are useful for local recovery
during a long run but are not required as independent downstream entry
points because the final annotated object above supersedes them:

- `decont_merged_obj.rds`
- `decont_merged_filt_obj.rds`
- `decont_merged_filt_nodoub_obj.rds`
- `decont_merged_filt_nodoub_cc_sct_obj.rds`
- `decont_merged_filt_nodoub_cc_sct_reduc_obj.rds`
- `decont_merged_filt_nodoub_cc_sct_reduc_clust_integ_obj.rds`

These intermediate objects can be regenerated by running the upstream
single-cell workflow and are therefore not planned for the external archive.

## Redistribution note

These RDS files contain author-generated analysis objects derived from the
input datasets described in `DATA_SOURCES.md`. Third-party raw/source data
remain subject to the access and redistribution terms of their original
repositories and providers.

## Integrity

File sizes and SHA-256 checksums will be recorded immediately before the
external data release so that archived files can be verified after download.
