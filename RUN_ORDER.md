# Analysis run order

This file summarizes the recommended execution order for the analyses in
this repository. Detailed input/output requirements are provided below.

## 1. Human single-nucleus multiome workflow

### 1.1 Single-nucleus preprocessing, integration, and annotation

Run:

`scripts/01A_Single_Cell_Analysis.R`

Default inputs:

- `data/GSE268953/RNA_ATAC/`
- `data/GSE268953/Fragments/`

Each RNA/ATAC sample directory is expected to contain the standard 10x
matrix files (`matrix.mtx.gz`, `features.tsv.gz`, and `barcodes.tsv.gz`).
ATAC fragment files are expected under the corresponding sample directories
in `Fragments/`.

Machine-specific input locations can be supplied with:

- `GSE268953_RNA_ATAC_DIR`
- `GSE268953_FRAGMENTS_DIR`

Principal final checkpoint:

`outputs/decont_merged_filt_nodoub_cc_sct_reduc_clust_integ_annot_obj.rds`

The script also writes intermediate RDS checkpoints to `outputs/`.
These large checkpoints are described in `LARGE_FILES.md`.

Compact reproducibility outputs include:

- `processed_results/01_QC/scDblFinder_doublets_summary.txt`
- `processed_results/02_differential_expression/bulk_de_sig.csv`
- `processed_results/02_differential_expression/bulk_de_sig_faps.csv`


### 1.2 Cell-composition analysis

Run:

`scripts/01B_Cell_Proportion_Test.R`

Default input:

Principal numerical output:

`outputs/hdWGCNA/`

## 2. GWAS, SMR/HEIDI, colocalization, COJO, and fine-mapping

### 2.1 GWAS preparation

Run:

`scripts/03_GWAS_Preparation.R`

Default raw inputs:

- `data/GWAS/UKB/shortfinalINGallMAFge05padjplusxxy.txt`
- `data/GWAS/FinnGen/finn-b-K11_HERING.vcf.gz`

Machine-specific raw input locations can be supplied with:

- `UKB_GWAS_RAW`
- `FINNGEN_GWAS_RAW`

Principal outputs:

- `data/GWAS/UKB/UKB_gwas_for_smr.txt`
- `data/GWAS/UKB/UKB_gwas_for_xqtlbiolinks.txt`
- `data/GWAS/FinnGen/Finn_gwas_for_smr.txt`
- `data/GWAS/FinnGen/Finn_gwas_for_xqtlbiolinks.txt`

These standardized files feed the downstream SMR/HEIDI,
locus-definition, colocalization, COJO, and fine-mapping workflows.


### 2.2 SMR and HEIDI

Run:

`scripts/04_SMR_and_HEIDI_Analysis.ps1`

The analysis evaluates both inguinal-hernia GWAS datasets (UK Biobank and
FinnGen) against GTEx v8 eQTL data from four tissues:

- Adipose - Subcutaneous
- Adipose - Visceral (Omentum)
- Muscle - Skeletal
- Cells - Cultured fibroblasts

This gives eight GWAS x tissue SMR/HEIDI analyses.

The SMR executable can be supplied through:

`SMR_EXE`

Combine the eight result sets with:

`scripts/04B_Combine_SMR_Results.R`

Principal combined output:

- `processed_results/06_SMR_HEIDI/SMR_all_studies_all_tissues.csv`

Apply the revised discovery/replication multiple-testing framework with:

`scripts/06C_SMR_Discovery_Replication_Audit.R`

For UK Biobank discovery, Benjamini-Hochberg correction is applied jointly
across all valid gene-tissue SMR tests from the four GTEx tissues.
Canonical corrected discovery outputs are:

- `processed_results/06_SMR_HEIDI/UKB_discovery_cohortwide_BH.csv`
- `processed_results/06_SMR_HEIDI/UKB_discovery_cohortwide_BH_genes.csv`

The exact gene-tissue hypotheses carried forward from UK Biobank are
evaluated in FinnGen as a targeted replication family, with
Benjamini-Hochberg correction across the two replication hypotheses:

- `processed_results/06_SMR_HEIDI/targeted_FinnGen_replication.csv`

HEIDI is retained as a heterogeneity diagnostic (`p_HEIDI > 0.01`) and is
not a multiple-testing correction. The revised workflow does not use
nominal `p_SMR < 0.05` as a downstream significance criterion.

### 2.3 Integration of candidate-gene evidence

Run:

`scripts/05_Upset_Plot.R`

Principal inputs include:

- `processed_results/05_hdWGCNA/module_assignment_table.csv`
- `processed_results/02_differential_expression/bulk_de_sig_faps.csv`
- `processed_results/06_SMR_HEIDI/UKB_discovery_cohortwide_BH_genes.csv`

This step integrates differential-expression, hdWGCNA, and corrected UK
Biobank SMR discovery evidence to generate the candidate-gene intersection
used in Figure 10. FinnGen is subsequently used for targeted replication
of the carried-forward SMR hypotheses.

### 2.4 SMAD3 locus definition

Run:

`scripts/06A_Locus_Definition.R`

The canonical locus is chromosome 15, hg19, SMAD3 +/-250 kb
(bp 67,107,940-67,737,507).

Default inputs:

- `data/GWAS/UKB/UKB_gwas_for_xqtlbiolinks.txt`
- `data/GWAS/FinnGen/Finn_gwas_for_xqtlbiolinks.txt`

Optional overrides:

- `UKB_GWAS_XQTL`
- `FINNGEN_GWAS_XQTL`

Principal outputs:

- `data/GWAS/UKB/UKB_SMAD3_250kb.txt`
- `data/GWAS/UKB/SMAD3_UKB_rs.tsv`
- `data/GWAS/FinnGen/Finn_SMAD3_250kb.txt`
- `data/GWAS/FinnGen/SMAD3_Finn_rs.tsv`

Both chromosome and genomic-position filters are applied during locus
extraction.


### 2.5 1000 Genomes EUR LD-reference construction

Run with PowerShell:

`scripts/06B_LD_Correlation_Matrix.ps1`

Required command-line software:

- PLINK 2
- PLINK 1.9

The executable locations can be supplied through:

- `PLINK2_EXE`
- `PLINK_EXE`

The 1000 Genomes reference directory can be supplied through:

`REF_1000G_DIR`

The reference directory is expected to contain the chromosome 15 Phase 3
PGEN/PVAR/PSAM reference files and `EUR_samples.keep`.

Principal outputs:

- `UKB_SMAD3_1000G_EUR.bed/.bim/.fam`
- `UKB_SMAD3_1000G_EUR_LD.ld`
- `Finn_SMAD3_1000G_EUR.bed/.bim/.fam`
- `Finn_SMAD3_1000G_EUR_LD.ld`

These cohort-specific reference subsets are used by GCTA-COJO and SuSiE.


### 2.6 GCTA-COJO

First prepare the summary-statistic inputs:

`scripts/07A_GCTA-COJO_Preparation.R`

Principal outputs:

- `data/GWAS/UKB/UKB_SMAD3_for_GCTA.tsv`
- `data/GWAS/FinnGen/Finn_SMAD3_for_GCTA.tsv`

The locus-file locations can optionally be overridden with:

- `UKB_SMAD3_LOCUS`
- `FINNGEN_SMAD3_LOCUS`

Then run:

`scripts/07B_GCTA-COJO.ps1`

The GCTA executable can be supplied through:

`GCTA_EXE`

The 1000 Genomes reference location can again be supplied through:

`REF_1000G_DIR`

Principal COJO settings:

- `--cojo-slct`
- `--cojo-p 5e-5`

Canonical results are written under:

`processed_results/07_GCTA_COJO/`

for both UK Biobank and FinnGen.


### 2.7 Standard colocalization

Run:

`scripts/08_Colocalization.R`

Principal inputs:

- GTEx v8 eQTL summary data
- UK Biobank standardized GWAS summary data
- FinnGen standardized GWAS summary data

Default local inputs are resolved from `data/`; the script also supports
environment-variable overrides for local copies.

Principal outputs are written under:

`processed_results/08_colocalization/`


### 2.8 SuSiE fine-mapping

Run the canonical implementation:

`scripts/09A_SuSiE_Reproducible.R`

Principal inputs:

- UKB and FinnGen SMAD3 locus GWAS files
- corresponding 1000 Genomes EUR BIM files
- corresponding LD correlation matrices

Default inputs are resolved from `data/GWAS/` and `data/1000Genomes/`;
machine-specific copies can be supplied through the environment-variable
overrides defined at the top of the script.

Principal outputs:

- `processed_results/09_SuSiE/`
- `source_data/figure_source_data/Figure_11/`

`scripts/09_SuSiE.R` is superseded and is not part of the canonical
reproduction workflow.


### 2.9 SuSiE-based colocalization

Run:

`scripts/10A_SuSiE_COLOC_Reproducible.R`

Principal inputs:

- GTEx v8 eQTL data
- UKB and FinnGen SMAD3 locus GWAS files
- corresponding BIM files and LD matrices

Default inputs are resolved from the repository data layout and can be
overridden with the environment variables defined in the script.

Principal outputs:

- reproduced SuSiE-colocalization results under `processed_results/09_SuSiE/`
- `source_data/figure_source_data/Figure_12/`

`scripts/10_SuSiE_COLOC.R` is superseded and is not part of the canonical
reproduction workflow.
